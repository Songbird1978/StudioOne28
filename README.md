# StudioOne28 - Full Stack Website for Music Studio and Producer

A responsive business website for a recording and production studio.

## Quick Access

 Jump straight to the site:
**[View Web Projects →](https://studioone28.com)**

## What's Inside

## Navigation
Drop down menus and side bar menus depending on screen size.

### Business Information & Contact pages
Separate pages for Studio and Musical services offered. 

### Music Production Work
Music Players for different areas of production work with examples and links

### Live Performance Work 
Different Galleries (tiled) with modal for zooming in on an image.

### Client Pages 
- reviews 
- Links to artist websites
- Client List with Links
  
## Tech Stack
React, Strapi, JavaScript, Render, Vercel, CSS Animations, Framer-motion, Audio API, phosphor-icons, react-responsive-masonry, 

## Future Work 
Add client side login to backend (Access at the moment is via strapi/logon and more SEO and marketing work.

## Navigation
Drop down menus on larger screens and burger menu with accordian style blocks to open sub-menus
